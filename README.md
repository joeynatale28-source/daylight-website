# daylight website

A static, responsive marketing website for daylight. No build step or framework is required.

Open `index.html` or serve this folder with any static server. The site lives at the repo root so GitHub Pages (main / root) publishes it directly.

## Screenshot assets

Replace the seven named placeholder files in `assets/screenshots/` with real PNG exports. Keep the filenames and aspect ratios documented beside each image in `index.html` so the layout remains stable.

## Brand assets

`assets/logo-black.svg` and `assets/logo-white.svg` are vector versions of the supplied sun-arc marks. The SVG favicon set is derived from the black mark.
